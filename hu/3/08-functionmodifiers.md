Nagyszerű! A zombink most már működőképes cooldown időzítővel rendelkezik.

Ezután hozzáadunk néhány további segédfüggvényt. Létrehoztunk egy új fájlt neked `zombiehelper.sol` néven, amely importálja a `zombiefeeding.sol`-t. Ez segít a kódunk szervezésében.

Tegyük úgy, hogy a zombik speciális képességeket kapnak, miután elérnek egy bizonyos szintet. De ehhez először egy kicsit többet kell tanulnunk a függvény módosítókról.

## Függvény módosítók argumentumokkal

Korábban az `onlyOwner` egyszerű példáját néztük meg. De a függvény módosítók argumentumokat is vehetnek fel. Például:

```
// Egy mapping egy felhasználó életkorának tárolásához:
mapping (uint => uint) public age;

// Módosító, amely megköveteli, hogy ez a felhasználó egy bizonyos életkornál idősebb legyen:
modifier olderThan(uint _age, uint _userId) {
  require(age[_userId] >= _age);
  _;
}

// 16 évnél idősebbnek kell lennie, hogy autót vezessen (az USA-ban, legalábbis).
// Az `olderThan` módosítót argumentumokkal így hívhatjuk meg:
function driveCar(uint _userId) public olderThan(16, _userId) {
  // Néhány függvény logika
}
```

Itt láthatod, hogy az `olderThan` módosító argumentumokat vesz fel, pont úgy, mint egy függvény. És hogy a `driveCar` függvény átadja az argumentumait a módosítónak.

Próbáljunk meg létrehozni egy saját `modifier`-t, amely a zombi `level` tulajdonságát használja a speciális képességekhez való hozzáférés korlátozásához.

## Tegyük próbára

1. A `ZombieHelper`-ben hozz létre egy `aboveLevel` nevű `modifier`-t. Két argumentumot vesz: `_level` (egy `uint`) és `_zombieId` (szintén egy `uint`).

2. A törzs ellenőrizze, hogy a `zombies[_zombieId].level` nagyobb vagy egyenlő-e, mint a `_level`.

3. Ne felejtsd el, hogy a módosító utolsó sora hívja meg a függvény többi részét `_;`-vel.
