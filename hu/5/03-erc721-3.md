Remek, merüljünk el az ERC721 implementációban!

Előre bemásoltuk az összes függvény üres vázát, amelyet ebben a leckében implementálni fogsz.

Ebben a fejezetben az első két metódust fogjuk implementálni: a `balanceOf`-ot és az `ownerOf`-ot.

### `balanceOf`

```
  function balanceOf(address _owner) external view returns (uint256 _balance);
```

Ez a függvény egyszerűen vesz egy `address`-et, és visszaadja, hogy az az `address` hány tokent birtokol.

A mi esetünkben a "tokenjeink" a Zombik. Emlékszel, hogy a DApp-unkban hol tároltuk, hogy egy tulajdonosnak hány zombija van?

### `ownerOf`

```
  function ownerOf(uint256 _tokenId) external view returns (address _owner);
```

Ez a függvény vesz egy token ID-t (a mi esetünkben egy Zombi ID-t), és visszaadja annak a személynek az `address`-ét, aki birtokolja.

Ez is nagyon egyszerű számunkra implementálni, mivel már van egy `mapping`-ünk a DApp-unkban, amely ezt az információt tárolja. Ezt a függvényt egy sorban implementálhatjuk, csak egy `return` utasítással.

> Megjegyzés: Emlékezz vissza, a `uint256` egyenértékű a `uint`-tal. Eddig `uint`-ot használtunk a kódunkban, de itt `uint256`-ot használunk, mert a specifikációból másoltuk be.
